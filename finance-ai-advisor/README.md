# 💰 Personal Finance AI Advisor

An AI-powered web application that analyzes personal expenses and provides smart financial insights, budgeting suggestions, and a financial health score.

---

## 🚀 Features

- 📊 Expense analysis by category  
- 💡 AI-based financial advice  
- 🏦 Financial health score (0–100)  
- 📈 Visual insights with charts  
- 📂 CSV file upload support  
- ⚡ Simple and interactive UI using Streamlit  

---

## 🧠 How It Works

1. Upload your expense CSV file  
2. Data is cleaned and preprocessed  
3. Expenses are analyzed by category  
4. AI generates financial insights  
5. Visual dashboard displays results
